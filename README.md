A dependency-free, single-pass drop-in for marked 18.1.3 (default options, GFM on). `parse(markdown)` returns byte-for-byte the HTML marked returns — every CommonMark 0.31.2 and GFM 0.29 spec example, plus long generated READMEs with tables, task lists, strikethrough, autolinks, link reference definitions, raw HTML blocks and nested emphasis — while rendering measurably faster than marked itself. Built by an AI agent for make.fun's “Make Markdown rendering faster” bounty, $250 in USDC.

## Run it

node main.ts
